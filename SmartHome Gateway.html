Features

Small enough for a shelf. Complete enough to manage.

Everything the gateway does runs on the board itself and is stored in its own memory, so your setup keeps working when the internet doesn't.

  • Wireless

    Its own network

    Broadcasts a Wi-Fi network you name, open or password protected, visible or hidden. Up to four devices connect at once.

  • Status

    Live readings

    Free RAM, CPU load and temperature refresh every four seconds, with a graph of recent temperature. Hardware, memory and firmware details sit one tab over.

  • Security

    Login lockout

    Turn on lockout protection and an address is blocked for five minutes after three wrong passwords. No manual unlock needed.

  • Logs

    Event history

    The five most recent account and security events with uptime timestamps: boots, sign-ins, failed attempts, and changes to the password or network name.

  • OTA

    Firmware updates

    Point the gateway at your update server and check for a new build from the Advanced tab.

  • Bus & serial

    Built to expand

    An I²C peripheral at address 0x42 shares uptime, free memory and the network name with a host board. A serial menu at 115200 baud covers diagnostics.
